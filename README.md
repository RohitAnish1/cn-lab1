# CN Lab 1

This repository contains the code and resources for the Computer Networks Lab 1 exercises and assignments. The primary programming language used in this repository is **C**.

## Repository Structure

- **Source Code:** All the implementation files are written in C.
- **Labs/Exercises:** Contains the lab assignments and exercises related to Computer Networks concepts.

## Prerequisites

- GCC Compiler or any C compiler of your choice.
- Basic understanding of Computer Networks concepts.

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/RohitAnish1/cn-lab1.git
2. Navigate to the repository directory:
   cd cn-lab1
3. Compile the C programs using a C compiler
   gcc -o output_file source_file.c
4. Run the compiled program:
   ./output_file
